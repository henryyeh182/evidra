# RR-2026-0001 — R0 package boundary

- proposer: Pacevera maintainers
- reviewer: Pacevera maintainers
- status: approved
- approved: 2026-08-10
- package: `base_rules@1.0.0`
- engine compatibility: `>=1.6.0 <2.0.0`

## Decision

The existing Rule Library is exposed through the `base_rules` package boundary.
This change moves ownership and validation of the rule files; it does not change
rule semantics, thresholds, arbitration, or decision output.

## Scope and limits

The package contains the cross-scenario base rules and engine parameters. Domain
packages remain empty draft packages. Archive installation, active pointers,
rollback, evidence uplift, and remote distribution are outside R0.

## Verification

The package manifest is validated against `rule-package.schema.json`; its content
checksum is verified; package-to-runtime tests compare Rule IDs and decision
contracts; and the Decision Harness is run against the package-loaded runtime.
